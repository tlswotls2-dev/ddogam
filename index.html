🌿 또감 사용법
걷고, 수집하며, 배워요!
👟
STEP 1. 탐험 시작!
주황색 탐험 버튼을 눌러요.
🚶
STEP 2. 주변을 걸어요!
화면을 끄지 말고 주머니에 넣고 걸어요. 진동이 울리면 안전한 곳에서 확인!
📖
STEP 3. 카드를 수집해요!
도감을 완성하며 레벨을 올려요!
🎯
STEP 4. 레벨업 퀴즈!
퀴즈를 풀고 레벨을 올리면 다음 단계를 해금할 수 있어요!
Lv.5 → 동물 해금  Lv.10 → 유물 해금
📚 자세한 사용법
👟 탐험 방법
• 주황색 탐험! 버튼을 누르면 탐험 시작
• ⚠️ 걸을 때는 절대 스마트기기 화면을 보면서 걷지 마세요!
• 탐험 버튼을 누른 후 화면을 끄지 않고 주머니에 넣고 걸어요
• 걷다 보면 현재 위치 주변에서 랜덤으로 카드 등장
• 진동이 울리면 안전한 곳에 멈춰서 화면을 확인해요
• 30% 확률로 카드 3장 중 1장을 선택하는 이벤트 발생!
📖 도감
• 수집한 카드를 모두 볼 수 있어요
• 식물 100종, 동물 100종, 유물 100종
• 카드 희귀도: ★ 일반 / ★★ 희귀 / ★★★ 전설
• 카드를 탭하면 자세한 정보를 볼 수 있어요
• ⚗️ 조합소 탭에서 중복 카드를 새 카드로 바꿀 수 있어요
⚗️ 조합소
• 이미 가진 카드가 또 나오면 조합소에 쌓여요
• 중복 카드 5장을 선택해 새 카드로 조합!
• 전설 1장 이상 → 무조건 전설
• 희귀 4~5장 → 전설 50% / 희귀 50%
• 희귀 3장 + 일반 2장 → 희귀 100%
• 희귀 1~2장 + 일반 → 희귀 60% / 일반 40%
• 일반 5장 → 일반 75% / 희귀 15% / 전설 10%
⭐ 레벨 & 아이템
• 카드 10장마다 레벨업 퀴즈 도전!
• 퀴즈를 맞춰야 레벨이 올라가요
• Lv.5 달성 → 동물 탐험 해금
• Lv.10 달성 → 유물 탐험 해금
• 레벨에 따라 아바타/옷/아이템/펫/칭호 해금
• 아바타를 탭하면 꾸미기 화면으로 이동
📝 일일 시험
• 하루에 한 번 OX 퀴즈에 도전해요
• 내가 수집한 카드의 설명이 맞는지 틀리는지 맞춰요
• 정답이면 복주머니 1개 획득!
• AI 또감이가 취약 영역을 분석해줘요
• 자정이 지나면 다시 도전할 수 있어요
⚔️ 지식 배틀
• 같은 반 친구와 지식 대결!
• 카테고리 선택 후 1분 공부 → 자동 매칭
• 매칭 후 5문제(3분 제한)를 풀어 승부!
• 승리 → 복주머니 1개 / 무승부 → 복주머니 조각 1개
• 조각 2개를 모으면 복주머니 1개로 변환
• 하루 3회 제한 / 매칭 실패 시 AI 또감이와 배틀!
🎁 복주머니
• 일일 시험 정답 / 배틀 승리 시 받아요
• 선생님이 특별 선물을 보내줄 수도 있어요
• 아이템 → 복주머니 탭에서 확인·개봉해요
• 두구두구 애니메이션으로 카드를 뽑아요!
